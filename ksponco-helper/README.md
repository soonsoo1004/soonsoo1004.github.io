# 올팍 지금 — 올림픽공원, 지금 가도 될까?

올림픽공원에 가기 전 30초 동안 확인하는 한 장짜리 화면입니다.
한국체육산업개발(주)이 개방한 공공데이터를 그대로 받아 보여 줍니다. 가입·설치·광고·추적 없음.

- 화면: https://soonsoo1004.github.io/ksponco-helper/
- 만든 사람: AI 비서 린다 + 사람 운영자

## 무엇을 보여 주나

| 화면 | 데이터 | 갱신 |
|---|---|---|
| 지금 주차 대수와 혼잡 단계 | 올림픽공원 실시간 주차현황 (기관 API) | 화면을 열 때마다 기관 API 직접 호출 |
| 오늘·가까운 공연과 행사 | 올림픽공원 공연정보 (공공데이터포털 3037877, LINK형) | 화면을 열 때 기관 일정 페이지 직접 호출, 연결 실패 시 `data/events.json` |
| 시설 대관·행사 안내 | 올림픽공원 대관정보 (공공데이터포털 15015212) | 위 일정에 함께 표기 |
| 휠체어·고령 방문객 안내 | 기관 「주차 안내」 안내문 | 기관 안내문이 바뀌면 사람이 대조 |

## 숫자를 지어내지 않는 규칙

- 주차 대수는 기관 API가 준 값만 씁니다. 연결이 안 되면 **마지막 스냅샷 값과 받은 시각**을 그대로 보여 주고, "실시간 연결이 안 됐다"고 화면에 적습니다.
- 혼잡 단계의 경계(90% 이상 만차 / 70% 이상 혼잡 / 50% 이상 다소혼잡)와 총 2,200대는 기관 「주차장 예상 이용률 안내」 페이지에 적힌 그대로입니다. 우리가 만든 기준이 아닙니다.
- 공연이 있는 날 붐빈다는 식의 예측 문장은 쓰지 않습니다. 시간대별 예상치는 기관 페이지에서 직접 보도록 링크합니다.

## 스냅샷 갱신

```sh
python3 build_snapshot.py          # data/parking.json, data/events.json 갱신
```

화면은 원칙적으로 **브라우저가 기관 API·기관 페이지를 직접** 부릅니다. 스냅샷은 연결이 막힌 환경(사내망·오프라인)에서 보여 줄 대체 값이고, 위 스크립트로 언제든 다시 만들 수 있습니다. 서버도 비용도 들지 않습니다.

## 이 화면이 하지 않는 것

- 로그인·회원가입·쿠키·분석 도구를 쓰지 않습니다. 입력받는 값이 없습니다.
- 주차장에 자리를 예약하거나 대신 결제하지 않습니다.
- 기관 공식 서비스가 아닙니다. 최종 안내는 기관 홈페이지와 현장 안내를 따릅니다.
